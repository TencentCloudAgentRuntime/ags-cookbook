# Integrate Deployments with the Agent Runtime cloud Session service

This directory provides tutorials for integrating the Agent Runtime cloud Session service with Brain and Hands Deployments:

| Tutorial | What it demonstrates |
| --- | --- |
| [brain](./brain/README.md) | Persist DSH Agent multi-turn conversations to cloud Sessions and inspect the associated Events. |
| [hands](./hands/README.md) | Store Hands Deployment session routing information in Session, continue using the original workspace, and verify workspace isolation between Sessions. |

The tutorials are independent and can be run separately.
